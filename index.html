Immediate (default)

No framework, just browser physics.



Linear (linear-policy: strict)

This text reveals line by line within its group. Nothing moves until it is visible. Each line waits for the previous one to finish. The order is deliberate, and the pace is controlled.



Blocks are connected by group, not by position alone. A block starts only after the previous block in the same group has completed. Other groups are unaffected and can run independently.



This creates a strict, linear flow per group. You cannot skip ahead inside the sequence, but parallel groups remain free. One group finishes before the next block in that group begins.

Linear (linear-policy: skip-unseen)

Each block starts when it becomes visible. Lines still reveal in sequence, but visibility decides when a block enters the flow.



Blocks only wait for earlier blocks that were also visible. If a block was skipped, it does not block anything that comes after it.



This keeps the order where it matters, without forcing a strict path. You can scroll freely, and the sequence adapts instead of breaking.

Resize the window: lines are recalculated automatically.
